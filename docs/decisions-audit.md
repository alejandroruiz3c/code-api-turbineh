# Decisions audit — every model call on main (2026-10-13)

Scope: every call to a chat model or to the decider on `main` at `78db575` (PRs #75 to #85 and everything before
them), plus the deterministic code that takes the decisions a model must not take. Rule and measurements:
[ADR-0038](adr/0038-decisions-through-the-decider.md).

Types:

- **(a) decision** among discrete options → the decider (`Decider`: JEV primary, open decider fallback in the worker;
  the TurbineH AI gateway for generated apps).
- **(b) generation** of code or text → open models.
- **(c) deterministic** (compatibility, licences, permissions, test results, policy) → code, never a model.

Models: `gemma-4-26b-a4b-it` is the compiler model (`COMPILER_MODEL`); the Backup Coder slots are
`deepseek-v4-flash-0731` (primary) and `glm-5.2` (secondary); the adaptation coder runs them in the reverse order
(GLM-5.2 first, ADR-0034); the report writer is `glm-5.2` (`REPORT_WRITER_MODEL`). The decider is `jev-1.13.0` with
the open decider as fallback (`DECIDER_PRIMARY=jev`, `DECIDER_FALLBACK=open`).
